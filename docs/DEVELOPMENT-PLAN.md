# Ludo Nex — Development Plan

## Milestone 1: playable offline core
- Validate the procedural 3D board and portrait camera on a real Android device.
- Test 2-, 3-, and 4-player local matches.
- Verify entering from base, safe squares, captures, six bonus turns, exact finish, and winning.
- Improve computer difficulty so easy, normal, and hard have distinct decision-making.

## Milestone 2: premium presentation
- Add original sound design, music controls, haptics, scene transitions, and refined token animations.
- Add original board themes, dice finishes, token variants, profile avatars, and local statistics.
- Add accessible contrast, scalable text, and language selection.

## Milestone 3: release hardening
- Profile frame time and memory on low-end Android phones.
- Optimize meshes, shadows, texture sizes, and APK size.
- Test background/resume, interrupted games, local save recovery, and different display ratios.
- Create a private release keystore and produce a signed release build.

## Product boundaries
- The supplied Ludo screenshots are visual reference only.
- All Ludo Nex branding, UI composition, 3D models, token designs, effects, and sounds must be original or appropriately licensed.
- No online account, advertising, payment, or network permission is required for the offline first milestone.
